\# 🚦 Smart Traffic Simulator



A Java-based traffic simulation project that simulates vehicle movement and traffic signal control at a four-way intersection.



\## Features



\- Four roads: North, South, East and West

\- Vehicle management using Queue (FIFO)

\- Automatic selection of the busiest road

\- Traffic signal control

\- Vehicle waiting time tracking

\- Multiple simulation cycles

\- Final traffic statistics



\## Concepts Used



\- Java

\- Object-Oriented Programming (OOP)

\- Data Structures and Algorithms (DSA)

\- Queue and LinkedList

\- Classes, Objects and Constructors

\- Loops and Conditional Statements

\## How to Run



Compile the project:



```bash

javac -d . src\\\*.java

```



Run the simulator:



```bash

java src.Main

```
